## 三、每个影展都要现场核的四件事

征稿这件事没有跨届稳定的规律，下面四项一律以当届官方页面为准，不要沿用往届：

1. **截止日期与征件窗口** —— 不少是隔年或隔届，且会改期。
2. **首映要求** —— "世界首映 / 国际首映 / 地区首映"，以及"评选期间不得在线上公开"。
3. **时长与完成时间** —— 本片 5:31；完成日期按 v2.0 定稿记 2026-11-01。
4. **AI 政策** —— 是否要求披露、是否要求"人类作者实质性控制"、是否排除生成式影像。

## 五、发布顺序

1. 投一、二（可并行）。
2. 收到确认后再决定何时发社交媒体——**收件确认 ≠ 允许公开**，仍要看首映与"评选期间不得公开"条款。
3. 社交发布：B 站（科技/AI 区）+ 小红书 + X；技术长文投 Hacker News（"every pixel is a shader, every note is NumPy" 这类标题在那里有天然读者）。
4. 仓库什么时候转 public：转公开不等于放弃首映（绝大多数影展只看成片是否公开），但对"未公开"条款严格的先别转。
