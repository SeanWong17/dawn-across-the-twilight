# Technical note / 技术说明

For SIGGRAPH CAF, Prix Ars Electronica and any jury that asks how the film was made.
Every claim here is verifiable in the repository — that is the point of submitting a film
whose source is public.

---

## At a glance

| | |
|---|---|
| Runtime | 5:31 (5 min 31 s), 30 fps |
| Frame | 1920×1080, picture 2.39:1 letterboxed, subtitles in the lower bar |
| Shots | 24, across 8 chapters |
| Footage used | none — not one still, not one stock clip |
| Sound sources | none — score and effects synthesised from oscillators and noise |
| Narration | edge-tts `zh-CN-YunxiNeural`, −12% rate (narration cut only) |
| Rendering | Remotion 4, GLSL fragment shaders on CPU (ANGLE software GL) |
| Source | `github.com/SeanWong17/dawn-across-the-twilight` |

## Picture

Each shot is a single fragment shader in `src/chN/glsl/*.ts`, composed on a shared library
of noise, starfields, tone mapping and film grain (`src/lib/glsl.ts`). Shots are laid on
the chapter timeline and cross-dissolve over 0.6 s (`src/lib/Shot.tsx`).

Two things are worth a jury's attention:

**1. The motion is not hand-keyed.** Camera pushes, the sunrise, a black hole feeding and
evaporating, light leaving a pair of hands — every one is a uniform driven by the line
timings in `timeline.json`. When the text says the oceans boil away, the shader is already
at the point where it does. Re-timing a sentence re-times the shot.

**2. Geometry that is too expensive per pixel is computed once, in JS.** The probe swarm in
chapter 4 has thousands of bodies; `src/ch4/swarmTree.ts` builds it and passes it to the
shader as `vec4[]` uniforms instead of looping over it in the fragment stage.

Note on the "real-time" question: these are shaders, but the film is **not** a real-time
piece. It is rendered offline, frame by frame, on the CPU. It is a shader-generated film,
not a live performance — please file it under animation, not Real-Time Live.

## Sound

The score is generated by `scripts/gen_music.py`, one `build_chN` per chapter: detuned saw
ensembles, sine pads, filtered noise and convolution reverb. Effects are placed against the
same timeline as the picture — asteroid flybys, the last black hole's flash, whale song.
Each chapter is mixed twice (score only; score ducked under narration).

The submission cut is **score only**. There is no voice-over in it: the poem is read as
subtitles, in the lower bar, at the pace the music sets.

## Chapter joins

Rendered alone, each chapter opens and closes on black. In the full film, chapter *n+1*'s
picture dissolves in over chapter *n*'s final shot while the score runs continuously; the
narration gap across a join is 3.4 s. Two dark endings are kept deliberately (ch. 5, where
the light in the hands becomes a star; ch. 7, after the last black hole flashes out) — the
last chapter begins out of that darkness. Mechanism: `src/lib/join.tsx`, `scripts/gen_full.py`.

## Reproducibility

```bash
npm install                                   # Node 18+
python3 scripts/gen_tts.py chN                # narration cache (network)
python3 scripts/gen_music.py chN              # score + mixes
python3 scripts/gen_full.py                   # full-film layout
npm run render                                # both cuts into out/
```

A full render takes about 10 minutes on a 20-core machine at concurrency 8.

## Deliverables cut from one master

- `full_clean.mp4` — picture and score, no text (festival screening / archive)
- `full_en.mp4` — English subtitles primary (international submission)
- text layer `.mov` (ProRes 4444, alpha) — laid over the clean master to produce either
  subtitle cut; a wording change costs a minutes-long text render, not a shader re-render
- `.srt` / `.vtt` — Chinese, English, bilingual
